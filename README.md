# Politique de confidentialité — ShopTracker

Dernière mise à jour : 31/07/2026
## Qui sommes-nous
ShopTracker est une application développée par Kévin Hatterer, disponible sur le Google Play.

## Données collectées

**Données stockées uniquement sur votre appareil**
ShopTracker enregistre vos listes de courses, articles, prix et préférences directement sur votre téléphone (base de données locale). Ces données ne sont jamais transmises à nos serveurs, car nous n'en possédons pas. Elles sont supprimées si vous désinstallez l'application.

**Publicités (AdMob)**
L'application affiche des publicités fournies par Google AdMob. Google peut collecter certaines données (identifiant publicitaire, informations sur l'appareil) pour proposer des publicités pertinentes. Pour en savoir plus sur la gestion de vos données par Google, consultez : https://policies.google.com/privacy

**Achats intégrés**
Si vous achetez l'option "Supprimer les publicités", la transaction est traitée entièrement par Google Play. Nous ne recevons ni ne stockons vos informations de paiement.

## Partage des données
Nous ne vendons ni ne partageons vos données personnelles avec des tiers, à l'exception des données techniques nécessaires au fonctionnement d'AdMob et de Google Play Billing (gérées directement par Google selon leurs propres règles de confidentialité).

## Vos droits
Comme aucune donnée personnelle n'est stockée sur nos serveurs, vous conservez un contrôle total sur vos données via votre appareil : vous pouvez les supprimer à tout moment en désinstallant l'application.
